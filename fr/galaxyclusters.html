Détection d’amas de galaxies

Utilisation de la technique de la séquence rouge pour détecter des amas de galaxies jusqu’à z~0.7 dans les relevés CFHTLS/VIPERS et estimer leur richesse optique.

Pendant mon master, j’ai utilisé l’estimateur de richesse lambda de Rykoff et al. 2012, un code fondé sur la séquence rouge qui vise à réduire la dispersion entre la masse des amas de galaxies et leur richesse optique. J’ai traduit le code IDL original en Python et ajouté quelques fonctionnalités. Voici un dossier Dropbox avec tous les fichiers nécessaires pour faire tourner le code vous-même :)
