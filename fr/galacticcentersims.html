CODE : orbites périodiques dans des potentiels non axisymétriques

Code C++ utilisé dans Gallego & Cuadra 2017 pour estimer des orbites périodiques à 200 pc du centre galactique, là où domine le potentiel de la barre. Ces orbites ont servi de conditions initiales à une simulation hydrodynamique avec Gadget-2. La méthode d’identification des orbites périodiques s’appelle « technique de tir » (shooting technique). On part d’une hypothèse sur la vitesse initiale dans l’espace des phases x−y, où la composante x de la vitesse est nulle sur le demi-grand axe de l’orbite. Les équations du mouvement sont ensuite intégrées avec une méthode de Runge–Kutta d’ordre quatre dans le référentiel de la barre en rotation. L’hypothèse sur la vitesse initiale est alors optimisée jusqu’à obtenir une orbite périodique avec la précision relative souhaitée. Téléchargez le code ici : find_periodic_orbits.cpp
