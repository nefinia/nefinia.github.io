Galaxy Clusters Detection

Using the red-sequence technique to detect galaxy clusters up to z~0.7 in the CFHTLS/VIPERS surveys and estimate their optical richness.

During my master thesis, I utilize the lambda richness estimator from Rykoff et al. 2012. This is red-sequence based code that aims to reduce the scatter between the cluster mass and the optical richness of galaxy clusters. I translate the original IDL code into python and add some extra features. Here is a Dropbox folder with all necessary files to run the code by yourself :)
